# リンゴリラのホームページ

https://ringorila2025.github.io

このページは **GitHubのサイト上でファイルを書きかえるだけ** で更新できます。
保存すると、数分でページに出ます（アプリやAIは要りません）。

---

## ライブの予定を出す・直す

**何もしなくてOK。** 「リンゴリラのイベントカレンダー」（Googleカレンダー）から1日3回（9時・14時・21時）自動で読みます。

- 出るもの：今日以降の予定の **日付・タイトル・会場**、説明欄の **開場／開演／料金／チケット／前売／当日／出演／共演** で始まる行
- 出ないもの：説明欄のそれ以外の行（タグ・電話番号・メモなど）
- **まだ言えない予定** は、タイトルか説明欄に `#解禁前` を入れておく → ページに出ません
  （ほかに `🔒` `リハ` `スタジオ` が入っている予定も出ません）
- 会場はタイトルの `＠` の後ろから取ります（例：`音楽事故物件@高円寺ShowBoat`）。カレンダーの「場所」に住所を入れておくと「地図」のリンクが住所で開きます
- リストに最初から出るのは **2か月先まで**（少ないときは近い順に3件まで）。残りは「さらに見る」で開きます（`settings.toml` の `list_months` `list_min` で変えられます）
- ライブ予定の形は `settings.toml` の `layout`：`tate`（縦リスト）／`yoko`（横スクロール）／`tanura`（たぬら式）
- すぐ反映したいとき：上の **Actions** → 「ホームページを更新」 → **Run workflow**

## お知らせを書く（動画をあげた・グッズができた など）

1. `news.md` を開く → 右上の **鉛筆マーク**
2. 説明の下に1行足す：**日付 ＋ 空白 ＋ 文**（URLも書けます）
   ```
   2026-11-20 新しい動画をあげました！ https://youtu.be/xxxxxxxxxxx
   ```
3. **Commit changes**

- 日付の新しい順に5つ出ます（それより前は「前のお知らせ」にたたまれます）
- YouTubeのURLは、新しいお知らせ3つまで動画がそのまま出ます。ほかのURLは「Instagramで見る →」のようなボタンになります
- 2週間以内のお知らせには **NEW** が付きます
- 消すときはその行を消して保存

## 写真を足す

1. `photos` フォルダを開く
2. 右上 **Add file → Upload files**
3. 写真をドラッグして入れる → 下の緑の **Commit changes**

- 新しく入れた写真が先頭に並びます
- ページに出すときに自動で軽くして、撮影場所などの情報も消します
- 使える形：jpg / png / webp（iPhoneの HEIC はそのままだと出ません。共有で「JPEG」にしてから）
- 消すとき：写真を開く → 右上の「…」→ **Delete file**

## フライヤーを付ける

**ふだんは何もしなくてOK。** 松たぬら情報サイトに出ているリンゴリラのフライヤーを、自動でその日の予定に付けます。

別の画像にしたいとき・たぬらサイトに無いときは、`flyers` フォルダに **その日の日付の名前** で入れてください（こちらが優先）。
例：12月12日のライブなら `2026-12-12.jpg`

## スケジュール一覧の画像（Canvaで作ったもの）

ライブ予定のいちばん上に出ます。タップで大きく見られます。

1. Canvaで一覧のデザインを開く → **共有 → ダウンロード** → 形式 **JPG**、ページは **一覧のページだけ** → ダウンロード
2. GitHubで `schedule` フォルダを開く → **Add file → Upload files** → 画像を入れて **Commit changes**
3. 古い一覧の画像は開いて「…」→ **Delete file** で消す

- 2枚以上入れると、横にスワイプして見る形になります（名前の順）

## 動画

**何もしなくてOK。** YouTubeチャンネル（@ringorila2025）に動画をあげると、自動でいちばん新しい動画が先頭に出ます。
見せる動画を選びたいときだけ、YouTubeで再生リストを作って、`settings.toml` の `playlist = ""` にそのURLを貼ってください。

## グッズ

`shop.md` に1行ずつ書くと、商品のカードになります。**3つ以上になると横にゆっくり流れます**（さわると止まる）。

```
名前 | 値段 | 商品ページのURL | 画像
```

- 画像は `shop` フォルダに入れた画像のファイル名か、画像のURL（お店のページで商品の写真を長押し →「画像アドレスをコピー」）
- 売り切れたら、その行を消す
- お店（STORES）はロボットよけがあって自動では読めないので、商品は手で書きます

## 文章を直す

| 直したいもの | 開くファイル |
|---|---|
| バンド紹介 | `about.md` |
| お知らせ | `news.md` |
| グッズの商品 | `shop.md` |
| 名前・キャッチコピー・SNS・動画・お店・メールのアドレス・メンバー・色 | `settings.toml` |

開いたら右上の **鉛筆マーク** → 書きかえ → **Commit changes**。

`settings.toml` は **`" "` の中だけ** 書きかえてください（`"` を消すと動かなくなります）。

### メンバーを足す

`settings.toml` の `[[members]]` から `text = ""` までを丸ごとコピーして下に貼り、中身を書きかえる。

## 困ったとき

- 保存したのにページが変わらない → 5分待ってから、ページを再読み込み
- 上の **Actions** に赤い ✕ が出ている → たぬに連絡（直前の保存で書き方が崩れたことが多いです。
  ページは前の状態のまま残るので、壊れはしません）

## しくみ（さわらなくてOK）

- `tools/` … ページを作る仕組み
- `.github/workflows/site.yml` … 保存したとき・1日3回、ページを作って公開する
- カレンダーの読み取り用の **非公開URL** は、GitHubの鍵付きの場所（Settings → Secrets → `CAL_ICS_URL`）に入っています。カレンダー自体は非公開のままです
- 見た目を試す：ページのアドレスの後ろに `/preview.html` を付けて開く（試し場。検索には出ません）→ 「🎨 見た目を試す」→ 気に入ったら「LINEで送る」
- 公開前にメンバーに配る **見本の1ファイル** は `python tools/build.py --mihon` で `_mihon/` にできます（画像も中に入っています。GitHubには上げません）
- 見た目のCSSは `tools/template.html` の `<style id="mitame">` にまとまっています。チャッピー（ChatGPT）に作ってもらった見た目は、ここに入れかえれば本番に入ります。
- 今の見た目は「墨・曲線・やわらかなモノトーン」（2026-11-05、チャッピー案をもとにたぬが選んだもの）。見出しの字はカイセイ。前の四角い見た目の控えは、作業しているPCの `_mihon/もとのファイル_2026-11-05/`（公開されないフォルダ）にあります。
  `<style id="shikumi">` はタブやたたむ仕組みなので触らない
- メールのアドレスはページの文字の中には書かず、「メールする」を押したときに出します（迷惑メールよけ）
- アドレス自体も、だれでも読める settings.toml には書かず、GitHubの鍵付きの場所（Settings → Secrets → `CONTACT_MAIL`）に入れてあります。変えるときはそこを書きかえます

ほかのバンドで同じページを作るときは [ほかのバンドで使う.md](ほかのバンドで使う.md) を見てください。
